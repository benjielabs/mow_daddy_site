# 🌿 Mow Daddy Lawn Services — Static Website

This repository contains the official static website for **Mow Daddy Lawn Services**, a locally operated lawn care service based in Blountville, Tennessee. The site is intentionally lightweight, fast, and built as a single‑page experience with additional standalone legal pages.

---

## 🚜 About the Project
This site is designed to be:
- **Fast** — pure HTML/CSS, no frameworks, no build step  
- **Reliable** — deployed through Cloudflare Pages  
- **Mobile‑friendly** — responsive layout and smooth scrolling  
- **On‑brand** — playful, bold, and clean  
- **Legally complete** — includes all required policy pages for collecting phone numbers  

The homepage includes:
- Hero section with branding  
- Services overview  
- “Why Choose Us” section  
- Service area  
- Booking/contact section  
- Back‑to‑top button (grass‑blade style)  
- Footer with legal links
